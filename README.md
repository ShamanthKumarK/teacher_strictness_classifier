# Teacher Strictness Classifier

A machine learning project that classifies a teacher as **strict**, **moderate**, or **lenient** based on the marks they give students.

## How it works
The model takes three inputs:
- Internal 1 marks
- Internal 2 marks
- Assignment marks

From these, it predicts the teacher's strictness category.

## Models compared
- Decision Tree
- Random Forest
- Gradient Boosting
- Logistic Regression

## Dataset
A synthetic dataset of around 900 records, created for this project.

## Results
The models achieved over 90% accuracy on the dataset.
